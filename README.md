# STEM Code Lab

Repositorio de animaciones educativas creadas con Manim Community Edition.

## Estructura

- `styles/`: paleta global y estilos compartidos.
- `serie-probability/`: serie de probabilidad.
- `serie-calculus/`: serie de cálculo.
- `serie-icpc-problems/`: soluciones y problemas de programación competitiva.
- `computerscience-standalone/`: videos independientes de ciencias de la computación.
- `math-standalone/`: videos independientes de matemáticas.
